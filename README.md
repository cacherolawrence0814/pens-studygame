# ✏️ Trace & Learn

A gentle tracing game for kids. Trace the letters A to Z and the numbers 0 to 9 with a finger or a mouse.

## What kids learn
- **Letters:** the shape of each capital letter (and small letters too), plus a picture word like "A is for Apple"
- **Numbers:** the shape of each number, plus counting objects (3 is three ladybugs)
- **Listening:** a Listen button says each letter or number out loud

## How it works
- Trace along the dotted shape. A progress bar fills as you go.
- When the shape is traced well, a star is collected and a cheerful message appears.
- Stars are saved in the browser, so progress is kept next time.

## Play it
Just open `index.html` in any browser. No install, no internet needed.

## Put it on GitHub Pages (free hosting)
1. Create a new repository on GitHub, for example `trace-and-learn`.
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute your game is live at `https://YOUR-USERNAME.github.io/trace-and-learn/`.
